# 頭カメラの外部パラメータ (head_link -> camera_link) のずれ

2026-10-15 の調査メモ。推定した値はまだ `launch/decompress.launch` /
`scripts/solve_palm_ik.py` に反映していない (今の値は 2026-09-24 の
handeye 較正 fdafe89 のまま)。ツールの使い方は
[`dev_tools.md`](dev_tools.md#頭カメラの外部パラメータの較正)。

## 見つけた経緯

2026-10-15 17:11/17:13 の実機 2 試行で、押し込み直前の手の再検出
(`press_in_refine`) が `no_hand`/`too_large` になり、検出した掌が計画時の
掌から 9cm/13cm ずれていた。人は手を動かしていなかったので、計測側を
順に調べた。

- PC とロボットの時計 (0.02 秒)、画像の遅れ (0.14 秒)、関節の平滑化
  (1cm 以内)、差し出し時の首の動き、hover の neck_r、/scan による台車
  補正の符号は、いずれも原因ではなかった。
- 計画時と押し込み直前の掌の差を差し出し時の座標で見ると、差し出し時の
  視線に垂直な横向きが主 (8cm/13cm、2 試行とも同じ側) で、距離 (1.5m/1.8m)
  に比例していた。奥行きの誤差なら視線方向に出るので、角度の誤差。
- 深度点群の /scan と同じ高さの断面を /scan に合わせると、台車静止中・
  首ヨー -12〜+20deg・hover (腰ヨー 55deg) のどれでも、カメラ位置まわりに
  +4.0〜4.5deg 回すと合った (深度の縮尺は 1.00)。首や腰の角度によらない
  一定のずれ。床も base_link 系で z = -5〜-16cm に傾いて見えていた。
- カメラ由来の点を約 4deg 回すと、2 試行とも横のずれがほぼ消えた
  (試行 2: 12.5cm -> 0.4cm)。残りは差し出し時の視線方向 3.5〜5cm と、
  高さ -3〜4.5cm。

データで言えるのはカメラと /scan の相対的なずれまでだが、カメラ側の
ずれと判断した。

## 推定 (首のスイープ)

`record_head_calibration_sweep.py` で初期姿勢 (腰 0deg・脚を伸ばした姿勢)
のまま首だけを動かして 2 か所で録り、`calibrate_head_camera.py` で推定した。

| データ | 補正 (camera_link 系) 回転 rpy [deg] | 並進 [mm] |
|---|---|---|
| 1 か所目 (首ヨー ±40 x ピッチ 0/15/30、47 時刻) | (-3.8, -1.2, +3.9) | (-34.5, -3.6, +9.2) |
| 2 か所目 (間仕切り前、首ヨー ±60 x ピッチ 15〜30、80 時刻) | (-4.4, -1.6, +2.8) | (-36.8, -3.8, +10.1) |
| 2 か所まとめて | (-4.3, -1.4, +3.1) | (-37.5, -3.7, +10.2) |

2 か所まとめた値 (未反映):

```
head_to_camera_link args:
  0.02918 0.00703 0.19434 -0.004963 -0.024023 0.012764 0.999618
(旧: 0.06700 0.01038 0.18521 0.032565 -0.0105949 -0.012757 0.999332)
```

base_link 系に直すと、首の向きによりヨー +3.6〜5.1deg。head_end_coords の
+Z と光軸の角度は 11.3 -> 12.8deg になる。

### 当てはまり

| bag | 値 | 床の高さ \|平均\| | /scan まで中央値 | 3cm 以内 |
|---|---|---|---|---|
| 1 か所目 | 今の値 | 6.4cm | 14.7cm | 0.11 |
| 1 か所目 | 1 か所目の推定 | 1.1cm | 3.5cm | 0.38 |
| 10/13 試行 22 (別の日・場所) | 今の値 | 5.4cm | 8.4cm | 0.20 |
| 10/13 試行 22 | 1 か所目の推定 | 4.7cm | 4.7cm | 0.47 |

試行 22 の床の 4.7cm は床が映っていない姿勢 (+14cm と誤認) が押し上げて
いる。回転だけ直す (`--fix-translation`) より並進も含めたほうが /scan と
はっきり合う (1 か所目で 3cm 以内 0.15 -> 0.38)。

### ばらつきと残る誤差

- 外側ループの最後の 2 回の変化は回転 0.2deg・並進 0.3mm 以下、点の間引きの
  乱数による差は 0.01deg。1 姿勢ずつ抜いた推定のばらつきは回転 0.1deg・
  並進 1〜2mm。場所の違いは回転 1deg 以内・並進 2〜3mm。
- 首を左に向けた時刻だけ / 右に向けた時刻だけで推定すると、camera_link の
  ロールが 3〜4deg 食い違う (base_link 系ヨーで 2.6 対 5.1deg、
  1.4 対 4.4deg)。2 か所とも同じ向き・同じ大きさなので環境ではなく、首の
  向きで変わる運動学の誤差 (首ヨー軸の傾き等) の疑い (未確認)。固定の
  取り付け値では左右それぞれ ±1.2deg 程度 (1.8m 先で ±4cm) 残る。台車を
  回して計測を増やしてもこの差は減らないので、減らすなら首の運動学の補正も
  一緒に推定する必要がある。
