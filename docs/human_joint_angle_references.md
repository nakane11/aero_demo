# 手を繋いだ後の人の姿勢の評価（LUBA にもとづく制約・候補）

手を繋いだ後（押し込み〜横並び）にロボットが選ぶ姿勢で、人の関節を傷めない・つらくさせないための方針と実装。
実装は `scripts/side_by_side_transition.py`（2026-10-27、実機未確認）。

## 1. 方針の要約

基準は LUBA（Kee & Karwowski 2001）だけを使う。

| 役割 | 方針 | 対象 |
|---|---|---|
| 制約（傷めない） | LUBA の最後の段階（可動域の端を含む段階）に入らない | 腕を下ろす途中と終点 |
| 候補（目標の姿勢） | LUBA で一番楽な段階を目標の姿勢にし、それで解けないときだけ楽さを1段落とした予備の候補を試す。候補の数は計算時間のために絞る | 腕を下ろした終点 |

## 2. LUBA

Kee & Karwowski, "LUBA: an assessment technique for postural loading on the upper body based on joint motion discomfort and maximum holding time", *Applied Ergonomics* 32:357–366, 2001（[PDF](https://iems.ucf.edu/wp-content/uploads/2015/03/LUBA-An-Assessment-Technique-For-Postural-Loading-Based-On-Joint-Motion-Discomfort-And-Maximum-Holding-Time.pdf)、表2〜4）。

- 健常な若い男性20人が、各関節を1方向だけ動かした姿勢を60秒保ち、不快度をマグニチュード推定法で答えた実験。可動域の 0/25/50/75/100% で測り、統計的に差のない点をまとめて、見て分かる角度に丸めている。
- 不快度スコアは「肘の屈曲 0〜45° を 1」とした比率尺度。
- 関節角度ごとの不快度を実験で測った指標なので、これを使う。

**立位のスコア**（人は立っているので立位の値を使う）。太字が制約の上限（最後の段階の始まり）。

| 関節・動き | LUBA の段階（立位スコア） |
|---|---|
| 肩 屈曲 | 0–45°: 1 / 45–90°: 3 / 90–**150°**: 6 / >150°: 11 |
| 肩 伸展 | 0–20°: 1 / 20–45°: 3 / 45–**60°**: 6 / >60°: 10 |
| 肩 外転 | 0–30°: 1 / 30–**90°**: 3 / >90°: 7 |
| 肩 内転 | 0–10°: 1 / 10–**30°**: 2 / >30°: 8 |
| 肩 内旋 | 0–30°: 1 / 30–**90°**: 2 / >90°: 5 |
| 肩 外旋 | 0–10°: 1 / 10–**30°**: 2 / >30°: 5 |
| 肘 屈曲 | 0–45°: 1 / 45–**120°**: 3 / >120°: 5 |
| 前腕 回内 | 0–**70°**: 2 / >70°: 7 |
| 前腕 回外 | 0–**90°**: 2 / >90°: 7 |
| 手首 掌屈 | 0–20°: 1 / 20–**60°**: 2 / >60°: 5 |
| 手首 背屈 | 0–20°: 1 / 20–**45°**: 2 / >45°: 7 |
| 手首 撓屈 | 0–10°: 1 / 10–**30°**: 3 / >30°: 7 |
| 手首 尺屈 | 0–10°: 1 / 10–**20°**: 3 / >20°: 6 |

## 3. どの段階で人の姿勢を考慮するか

| 段階 | 人の姿勢を決めるもの | 扱い |
|---|---|---|
| 差し出し〜押し込み | 人自身。ロボットは差し出された掌に手を合わせるだけ | 評価しない。押し込み時の姿勢を以後の基準にする |
| 横並び中（段階1：腕を下ろす） | 人の腕を下ろす動き（`HumanArm.lowering`、モデル）と、ロボットの握りの向き | 制約。数秒の動きなので、傷めない上限だけを見る |
| 寄せ（段階2：台車だけ寄る） | 人の腕は動かさない | 制約（手首だけ。肩・肘・前腕は段階1の終点のまま） |
| 横並びの終点 | 段階1・2の終点 | 制約と候補。長く保つ姿勢なので、候補は LUBA で楽な段階から選ぶ |
| 横並び後に歩く | 人自身（計画外） | 対象外 |

- 押し込み（ロボットが掌を数cm押す）で人の手首が背屈側へ押される分は、押し込み量が小さいので評価しない。
- 人の肩・肘・掌の向きは下ろし方だけで決まる。ロボットの握りの向き（掌の法線まわりの回転）が変えるのは、手首の掌屈・背屈と撓屈・尺屈だけ。そのため、肩・肘・前腕は下ろし方ごとに IK の前に判定でき、手首は IK の後に waypoint ごとに判定する。
- 首・腰は判定しない。計画で人の体幹は動かさないため。

## 4. 制約：LUBA の最後の段階に入らない

**上限は、LUBA の最後の段階（可動域の端を含む段階）の始まりの角度**（2節の表の太字）。

理由：
- LUBA は可動域の 0/25/50/75/100% で測っているので、最後の段階の始まりは、おおむね可動域の 3/4 にあたる。傷めるかどうかに効くのは可動域の端からの余裕で、個人の可動域は測れないので、これで代用する。
- 段階ごとのスコアの増え方（差）は、全関節で最後の段階の始まりが一番大きい（肘だけは 45° と 120° が同じ +2）。上限は「不快度が一番大きく跳ねる境目」でもある。

実装（`HUMAN_ARM_LIMITS_DEG`、`HUMAN_WRIST_*_MAX_DEG`）:

| 関節 | 上限 | 判定する場所 |
|---|---|---|
| 肩 | 屈曲150°・伸展60°、外転90°・内転30°、内旋90°・外旋30° | 下ろし方ごとに、腕を下ろす途中10点（`HumanArm.lowering_problem`） |
| 肘 | 屈曲120° | 同上 |
| 前腕 | 回内70°・回外90° | 同上 |
| 手首 | 掌屈60°・背屈45°・撓屈30°・尺屈20° | 移動先の IK の後と、経路の全 waypoint（人の手をロボットの手に固定したモデル） |

判断が入っている点と、その理由:
- **押し込み時にすでに上限を超えている成分**は、「押し込み時の値＋5°」まで超過を許し、この許容を腕を下ろす割合 s に比例して狭め、下ろしきった時点で上限どおりにする（`arm_limits`、`wrist_limits`）。人が自分で差し出した姿勢で計画が止まらないようにするため。5° は骨格・掌の推定誤差の見込み。
- **関節角度の分け方は自前の定義**（肩の屈曲は上腕を前後の面に投影した角度、外転は前後の面からの角度、回旋は「腕を下ろして肘を曲げた前腕が前を向く向き」を基準）。LUBA は1方向だけ動かした姿勢で測っており、組み合わさった姿勢の分け方を決めていないため。
- **肘の曲げが20°未満では肩の回旋を判定しない**（回内・回外は上腕の回旋を含めた値で判定する）。肘が伸びていると、上腕の回旋と前腕の回内・回外を見分けられないため。
- **前腕のひねりは、絶対的な回内・回外だけで判定する。** 押し込み時からのひねりの変化量には LUBA の基準が無いため。手首の判定でのひねり（人の手をロボットの手に固定したときの、押し込み時からのひねり）は、ロボットが人の掌に合わせているかぎり腕のモデルのひねりと同じなので、回内・回外の判定で足りる（`--transition-twist-limit` で変化量の判定も足せる）。

## 5. 候補：一番楽な段階を目標にし、解けなければ1段落とす

腕を下ろした終点の候補（`LOWERED_ARM_GROUPS`、`LOWERED_PALM_FACINGS`）:

| 組 | 上腕（真下から） | 脇の開き | 肘 | LUBA |
|---|---|---|---|---|
| 1（目標） | 0・15・30° | 25° | 15° | 肩の屈曲 0–45°・外転 0–30°・肘 0–45° で、どれもスコア1 |
| 予備 | 0・15・30° | 40° | 15° | 外転が 30–90°（スコア3） |
| 予備 | 45・60・75° | 25°・40° | 15° | 肩の屈曲が 45–90°（スコア3） |

- 組1は、LUBA で一番楽な段階の中で、腕を体の横へ下ろした姿勢。これを目標にする。
- 組1で横並びまで解けない人のために、楽さを1段落とした予備の候補を試す。上腕を上げた組は、ロボットが人の手の低い位置まで届かないときのためのもの。
- 掌の向きは、前腕をひねらない向き（natural）・後ろ・人側・前の順に試す（掌が上向きの人は前・後ろ・natural・人側）。回内は LUBA で 0〜70° のスコアが一定なので、LUBA では差が付かない。ひねりの少ない向きを先にする。
- 候補の数は計算時間のために絞る（移動先のバッチ IK は呼び出しの回数で時間が決まる）。LUBA が許す姿勢をすべて試すわけではない。
- 候補が上限（4節）を超える下ろし方は、IK の前に外す。

## 6. 限界

- LUBA は若い男性20人が、自分で保った姿勢を60秒、関節ごとに1方向だけ、の実験。ロボットに手を引かれて受け身で動く場面、組み合わさった姿勢、高齢者・女性は対象外。
- LUBA の不快度は「つらさ」で、けがの起こりやすさを直接測ったものではない。
- 段階の境目は測った点の粗さで決まっており、境目そのものに生理的な意味はない。
- 横並び中の人の肩・肘は「肩から腕を下ろす」モデルの姿勢で、実際の人がその通りに動くとは限らない。
- 押し込み時の人の腕は、骨格の肩・手首と腕の長さから決めた肘で推定している。数cm・数度の誤差がある。
